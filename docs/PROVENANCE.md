# Provenance and reproduction limits

This public snapshot is curated from a private development worktree. It includes reusable implementations, invented software fixtures and a scientific methods/status summary. It excludes local machine/Studio identifiers, credential material, raw or derived research data, private review annotations, model artifacts and private run records. None of the synthetic test outputs are research results.

The local M2seal, M3environment/runtime evidence and M4selected artifact bindings are preserved privately. Aggregate methods/status statements summarize those checks; this public snapshot cannot independently rederive private membership or authenticate biological identities without separately permitted source access and approved protocols. Checkpoint/cache hashes verify bytes, not clinical validity. No license or redistribution permission for an upstream dataset/model is inferred from repository access.

Primary source identifiers:

- HAM10000: Harvard Dataverse DOI[10.7910/DVN/DBW86T](https://doi.org/10.7910/DVN/DBW86T).
- DenseNet: torchvision DenseNet121 IMAGENET1K_V1, official weight filename densenet121-a639ec97.pth;[torchvision DenseNet121 documentation](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.densenet121.html).
- MedSigLIP: google/medsiglip-448, immutable revision9cea28a1a1195f665105faa6e8544c112fd960a4;[pinned source](https://huggingface.co/google/medsiglip-448/tree/9cea28a1a1195f665105faa6e8544c112fd960a4).
- Dependency specifications: requirements-m2-integrity.txt and requirements-m3-model-dev.txt/lock.txt. Runtime compatibility must be checked on the actual platform; do not reuse a macOS OS profile unchanged on Linux.

Public portability changes are confined to this snapshot: local protected-data roots require explicit DERMDETECT_PROTECTED_SOURCE_ROOT; a generic transfer helper requires explicit destination/root matching its approval record; configuration tests use an invented fixture rather than private run outputs. Numerical model/data algorithms are preserved. Private source/evidence files are not overwritten. Approval examples in tests are labeled invented and grant no real access/compute authorization.

The original app, notebooks, sample images and legacy checkpoint already existed on the public main branch. This update neither removes them nor verifies their privacy, license, provenance, historical metrics or clinical quality. Their historical outputs are not a rebuilt baseline. No trained research model or medical image is newly added by this snapshot.

To reproduce software contracts, install an appropriate separately reviewed environment and run the synthetic tests. To reproduce research development, first establish source/use permissions, exact manifests/hashes and numerical policies, then authorize the concrete CPU/GPU budget/runtime and actual isolation checks. Internal-test/DDI remain excluded until frozen-system and explicit-unseal gates. Clinical use, new data redistribution, secret entry or uncontrolled cloud work are not authorized by these instructions.
